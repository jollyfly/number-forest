# 《数字森林》iPad 数学小游戏 · 整体计划（v0.1 草案）

> 给 5 岁小朋友玩的 iPad 游戏：在玩的过程中练习 **认数字（1–10）**、**10 以内加减法**、**逻辑思维**。
> 网页技术开发（HTML + SVG），套壳装到 iPad；所有画面素材自己用 SVG 画；代码放在你的 GitHub。
> 本文档只是计划，还没有写代码、没有建仓库。

---

## 1. 关键决策一览

| 事项 | 决定 |
|---|---|
| 装到 iPad 的方式 | **首选：PWA（网页应用）+ GitHub Pages**，Safari 打开后"添加到主屏幕"，全屏、可离线、免费、不需要 Mac。**备选：Capacitor 套壳成原生 App**，用 Xcode 装（需要 Mac）。两者共用同一份代码。 |
| 技术栈 | Vite + TypeScript（不用重框架），画面是 DOM 里的 SVG + CSS 动画 |

| 声音 | 音效用 Web Audio 实时合成；语音提示用 iPad 自带中文语音朗读（speechSynthesis）。可升级为打包好的预生成语音文件 |
| 交互原则 | 不需要识字、按钮够大、只鼓励不惩罚、每局 3–5 分钟、难度自动调节 |
| GitHub | 已连接账号 **jollyfly**（万志超）；建议仓库名 **`number-forest`**（目前不重名） |

## 2. 调研要点（简版）

**5 岁孩子的设计原则**
- **不靠文字**：所有指令都用语音说出来，画面上只有数字和图形；每个题目旁边有一个"小喇叭"可以再听一遍。
- **点击目标要大**：按钮和可拖动的东西至少 80–100pt，彼此间隔开；用"点一下"和"拖过去"，不用双指手势、长按或快速连点。
- **先具体后抽象**（CPA：实物 → 图形 → 符号）：先数苹果，再看十格框（ten-frame）里的圆点，最后才看算式"3 + 2"。十格框和数轴是公认最有效的两种 10 以内数感工具。
- **不惩罚失败**：答错时角色歪头说"再试试"，轻轻提示（比如让正确答案闪一下，或者帮孩子数一遍）；不扣分、没有失败画面、没有倒计时。
- **短时间、强反馈**：每关 5–8 道小题，答对有音效、星星和角色欢呼；每局 3–5 分钟。
- **自适应难度**：连对 3 题升一级，连错 2 题降一级并加提示。

**参考产品**（只借鉴思路，不照搬素材）
- **Khan Academy Kids**：有一套统一的角色世界，全程语音引导，只鼓励不惩罚 → 学它的"世界观 + 吉祥物"。
- **Todo Math**：用"大拇指 + 拖拽"的操作，难度分很多小级 → 学它的难度阶梯和描数字。
- **DragonBox Numbers**：数字是一个个能拆能合的"小生物"，让孩子直观感受 5 + 3 → 学它"数字就是东西"的思路（凑十、拆分）。
- **Moose Math**：把数学题做成在小镇里做事（开果汁店之类）→ 学它"做事情"式的任务包装。

## 3. 世界观与角色

**《数字森林》**：小熊猫 **"团团"** 住在森林里，要帮森林里的朋友们做事情，每帮完一件事就收集到一颗 **"星星果"**。收集得越多，团团的树屋就会长出新东西（装饰、新朋友、新地点）。

- **团团（吉祥物）**：圆滚滚的小熊猫，负责语音引导、做示范、欢呼。有 4 种表情动画：开心、思考、惊喜、鼓励。
- **配角**（每个对应一个地点或一类玩法）：
  - 松鼠 **栗栗**：喜欢数松果 → 认数字
  - 青蛙 **呱呱**：在荷叶数轴上跳 → 加减法
  - 小鸟一家：飞来飞去 → 减法
  - 猫头鹰 **博士**：出谜题 → 逻辑
- **地图**：一张能左右滑动的森林地图，上面有 4 个区域（松果林、荷花池、鸟儿树、猫头鹰塔），点哪个就进哪里。

## 4. 小游戏清单（对应学习目标）

难度等级记为 L1–L4，系统会按孩子的表现自动升降。

### A. 认数字（松果林 · 栗栗）

| # | 小游戏 | 玩法 | 难度递进 |
|---|---|---|---|
| A1 | **数松果** | 树上挂着几颗松果，孩子一颗颗点，点到哪颗就念"1、2、3…"，最后在 3 个数字气泡里选出总数 | L1：1–5 个，排得整齐 → L2：1–10 个 → L3：随意散开（得记住哪些数过了）→ L4：只闪现 2 秒（练一眼看出几个） |
| A2 | **戳气球** | 团团说"找到数字 7！"，孩子去戳写着 7 的气球 | L1：3 个气球，数字 1–5 → L3：6 个气球，数字 1–10，气球会慢慢飘 |
| A3 | **装松果车** | 小车车厢就是一个十格框，团团说"装 6 颗"，孩子把松果拖进格子 | L1：5 格框 → L2：10 格框 → L3：给出一个数字，把车装到这个数 |
| A4 | **描数字** | 用手指沿着虚线描 0–9，描完数字会"活"过来（比如 2 变成一只小鸭子） | 先跟着带箭头的路径描 → 再只给起点描 |

### B. 10 以内加减法（荷花池 · 呱呱 / 鸟儿树）

| # | 小游戏 | 玩法 | 难度递进（实物 → 图形 → 算式） |
|---|---|---|---|
| B1 | **果篮加法** | 先来 3 个苹果，又来 2 个，一共有几个？ | L1：苹果直接看得见，可以点着数 → L2：换成十格框里的圆点 → L3：圆点下面出现"3 + 2 = ?" → L4：只有算式（可以点"小喇叭"看圆点提示） |
| B2 | **小鸟飞走了**（减法） | 树枝上有 7 只小鸟，飞走 3 只，还剩几只？（有飞走的动画） | 与 B1 一样的 L1–L4 |
| B3 | **呱呱跳荷叶** | 荷叶连成 0–10 的数轴，"呱呱在 4，往前跳 3 下"，孩子点荷叶让它跳，再说出落在几 | L1：只往前跳（加法）→ L2：往后跳（减法）→ L3：给出算式，自己决定往哪跳 |
| B4 | **凑十好朋友** | 十格框里已经有 6 个，还要几个才能填满？配对成功的两个数会手拉手 | L2 之后开放；为以后学"凑十法"打基础 |
| B5 | **拆一拆**（数的分解） | 5 颗糖分给两只小动物，一共有几种分法？ | L3 才开放；练"5 = 2 + 3"这样的分解 |

### C. 逻辑思维（猫头鹰塔 · 博士）

| # | 小游戏 | 玩法 | 难度递进 |
|---|---|---|---|
| C1 | **找规律** | 珠子串成"红蓝红蓝…"，下一颗该是什么？ | AB → AAB → ABC → 数字规律（1, 2, 3, ?）（2, 4, 6, ?） |
| C2 | **分一分** | 把东西拖进对应的篮子：按颜色分 → 按形状分 → 按大小分 → 按两个条件同时分 | 篮子上只画图标，不写字 |
| C3 | **排排队** | 把 3–5 只动物按从小到大排好；或者给数字火车补上缺的那一节（3, _, 5） | 由 3 个到 5 个；从比大小到排数字顺序 |
| C4 | **比多少** | 天平两边放上东西，哪边重 / 哪边多？ | 先比实物 → 再比数字（为以后学 > < 做准备） |
| C5 | **团团回家**（编程启蒙） | 在网格地图上摆出"↑ → →"几张方向卡片，点"出发"，团团照着走 | L1：一步、两步 → L3：要绕开障碍 → L4：出现"重复 2 次"卡片 |

**MVP 先做 5 个**：A1 数松果、A3 装松果车、B1 果篮加法、B3 呱呱跳荷叶、C1 找规律。其余的按里程碑逐步加入。

## 5. 奖励与进度

- **星星果**：每完成一局（5–8 题）就得到 1–3 颗。**只要玩完就至少有 1 颗**，答得又对又快就多给。
- **树屋成长**：用星星果解锁装饰和新朋友（比如 5 颗解锁秋千、10 颗解锁小鸟来做客），让孩子对"进步"有看得见的感受。
- **贴纸册**：每个小游戏的每个难度等级各有一张贴纸，集齐了就点亮。
- **不做**：排行榜、限时、扣分、连续登录惩罚、内购、广告。
- 进度存在设备本地（IndexedDB/localStorage），不需要账号、不联网。

## 6. 家长设置

入口放在右上角一个小齿轮，需要**长按 3 秒**，或者回答一道大人才会做的题（如"7 × 8 = ?"）才能进入，免得孩子误碰。

- **单次时长**：10 / 15 / 20 分钟，或不限时。时间到了团团会打哈欠说"我们休息一下吧"，播完当前这局再停，不会突然中断。
- **难度**：自动（默认），或者每个领域手动锁定到 L1–L4。
- **开关小游戏**：比如暂时还不想让孩子做减法，就关掉。
- **声音**：语音 / 音效 / 背景音乐分别调节。
- **学习报告**：最近 7 天每个领域玩了多久、答对率、哪些数或算式容易错（比如 7 + 2）。
- **重置进度**。
- 另附一条提示：用 iPad 自带的"**引导式访问**"可以把孩子锁在这个 App 里，用"**屏幕使用时间**"可以从系统层面限时。

## 7. 声音与语音

**音效**：用 Web Audio API 实时合成，不需要任何音频文件。包括点击的"啵"、答对的上行音阶"叮咚"、答错的温和"嘟嘟"（不刺耳）、星星飞出的闪光声，以及简单的背景旋律（可以关掉）。

**语音提示**：用 `speechSynthesis` 调用 iPad 自带的中文语音朗读。
- **可行性**：iOS 的 Safari 和主屏幕 PWA 都支持，中文语音（如 Tingting）是系统自带的离线语音。
- **限制与对策**：
  1. iOS 要求**第一次发声必须由用户的点击触发**，否则系统会直接不出声 → 开场放一个大大的"开始"按钮（团团挥手），点它的同时解锁语音和音效。之后每道题的语音也都跟在孩子的点击后面触发。
  2. 只设置 `lang='zh-CN'` 不够，**必须从 `getVoices()` 里选中一个中文 voice**，否则可能用英文腔念。要监听 `voiceschanged` 事件，并且优先选本地语音（`localService`）。
  3. 系统语音听起来比较机械，可以把语速调到约 0.9、音调略微调高，让它更亲切；文本里避免出现 `<`、`>` 之类的符号。
  4. 静音开关打开时，Web Audio 可能没声音 → 家长设置里提示"请关闭静音"。
- **可选升级（M4）**：在构建时用 TTS 工具把所有固定台词（大约 100–200 句）预先生成音频文件打包进去，声音更自然、在任何设备上都一致。数字和算式由几段音频拼接。做不做由你决定（见"待确认问题"）。

## 8. 美术风格（SVG）

- **风格**：扁平 + 圆角，3–4px 深色描边，大眼睛 Q 版动物；配色是暖绿森林底色加高饱和的点缀色（红苹果、黄星星、蓝水池）。
- **色盲友好**：分类和规律题不只靠颜色区分，同时用形状或花纹。
- **素材组织**：每个角色或物件写成一个 TS 函数，返回 SVG 字符串或元素，可以传参数（颜色、表情）；动画用 CSS transform（弹跳、摇摆、眨眼）+ 少量 SMIL 或 JS 补间。
- **数字字形**：自己用 SVG 路径画一套 0–9 的圆润大数字，同时作为"描数字"游戏的路径数据。不依赖外部字体。
- **初步素材清单**（约 40–60 个）：团团 ×4 表情、栗栗、呱呱、小鸟、博士；苹果、松果、糖果、珠子、气球、荷叶、篮子、小车、天平；树屋及装饰；数字 0–9；UI 用的按钮、星星、小喇叭、齿轮；4 张场景背景。

## 9. 技术方案与架构

**技术栈**：Vite + TypeScript，不用 React 等框架。场景很简单，直接操作 DOM 里的 SVG 最轻、最好控制。只用一个依赖 `vite-plugin-pwa`，用来生成 Service Worker 和 manifest。测试用 Vitest，测出题逻辑和难度算法。

**架构**
```
App
├─ SceneManager      场景切换（开始页 → 地图 → 小游戏 → 奖励页 → 家长设置）
├─ games/*           每个小游戏实现统一接口：
│                    init(level) / nextQuestion() / onAnswer() / destroy()
├─ core/
│   ├─ question-gen  出题器（按等级随机，避免重复，保证 10 以内、结果不为负）
│   ├─ adaptive      难度自适应（连对升级、连错降级、记录易错题并多出几次）
│   ├─ progress      进度与星星果的存取（IndexedDB）
│   ├─ audio         Web Audio 音效合成 + 背景音乐
│   ├─ voice         speechSynthesis 封装（选 voice、排队播放、解锁、降级处理）
│   ├─ input         触摸、拖拽统一处理（Pointer Events，带吸附和大的判定区）
│   └─ timer         家长时长限制
├─ art/              SVG 角色、物件、数字（TS 函数）
└─ content/          台词文案（中文）、关卡配置（JSON/TS）
```

**iPad 适配**：横屏优先（同时兼容竖屏）；用 `viewport-fit=cover` 处理安全区；禁止双击缩放和页面回弹；关掉长按弹出菜单和文字选中。目标设备 iPadOS 16 及以上。

**离线**：Service Worker 预缓存全部资源。因为所有图都是 SVG 代码、音效是合成的，整个包很小（预计不到 1MB），第一次打开后完全离线可用。添加到主屏幕的 PWA，数据存储不会被 Safari 的 7 天清理规则清掉。

## 10. 装到 iPad 的方式

### 首选：PWA + GitHub Pages（零成本，不需要 Mac）
1. 代码推送到 GitHub，GitHub Actions 自动构建并发布到 `https://jollyfly.github.io/number-forest/`。
2. 在 iPad 上用 **Safari** 打开这个网址 → 点"分享" → "**添加到主屏幕**"。
3. 主屏幕上会出现团团图标，打开后全屏运行，没有地址栏，体验接近原生 App，离线也能玩。
4. 有更新时，下次联网打开就会自动更新（可以在家长设置里显示版本号）。

**缺点**：不在 App Store 里；要先用 Safari 打开一次；声音和语音受上面提到的网页限制。

### 备选：Capacitor 套壳成原生 App
- **适用情况**：你想要"真 App"，或者 PWA 的声音有问题。
- **需要**：一台 Mac + Xcode。用**免费 Apple ID** 签名，装到自己的 iPad 上 **7 天后会过期**，需要重新连 Mac 再装一次；用**付费开发者账号**（99 美元/年）签名有效期 1 年，还能用 TestFlight 发给家人。
- 代码基本不用改：`npx cap add ios` → 在 Xcode 里打开 → 选你的 iPad → 运行。
- 这一步放在 M5，可做可不做。

## 13. 需要你确认的问题

1. **有没有 Mac 和 Xcode？** 没有的话就只走 PWA 路线（推荐）。
2. **仓库公开还是私有？** 免费账号的私有仓库不能用 GitHub Pages，那样就需要改用 Cloudflare Pages 或 Netlify 之类（也免费）。建议用公开仓库，名字 `number-forest` 可以吗？
3. **iPad 的型号和系统版本？** 用来确认语音和 PWA 的兼容性。
4. **吉祥物用小熊猫"团团"可以吗？** 如果孩子有特别喜欢的动物或名字，可以换（也可以在游戏里叫孩子的小名）。
5. **语音**：先用 iPad 自带的中文朗读，听起来有点机器味；要不要在 M4 换成更自然的预生成语音？另外只要普通话，还是也要英文？
